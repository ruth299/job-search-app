# Melbourne JobDash - Live Job Search Tracker

A clean, modern, light-themed pipeline companion app built using vanilla frontend structures. 

## ✨ Features Added
- **Live LocalStorage Persistent Tracking:** Applications do not disappear when you refresh. Everything is captured straight into browser space memory.
- **Dynamic Kanban Flow:** Columns immediately scale and show reactive number badges dynamically updating as selections transition statuses.
- **Interactive Forms:** Directly load up new positions immediately via the control card UI dashboard.

## 🚀 How to Host via GitHub Pages
1. Push all files (`index.html`, `styles.css`, `jobs.js`) to your primary root directory.
2. Under repository **Settings** -> navigate to the **Pages** sidebar interface panel.
3. Select the `main` branch configuration parameters, and save.
